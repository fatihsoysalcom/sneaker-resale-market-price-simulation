# Sneaker Resale Market Price Simulation

This example simulates the dynamics of a sneaker resale market, demonstrating how factors like supply, demand, hype, and market saturation influence resale prices. It illustrates scenarios where prices can be significantly above retail, and critically, how they might fall below retail as predicted by the accompanying article for 2026.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
